## Windows review
- Claude Code launch: `claude.cmd` shims and `.exe` installs are both resolved without a shell (`resolveClaude`); long prompts go through stdin, and the arguments (system prompt + JSON schema) are under 5 KB, well under Windows' 32 KB command-line limit.
- Every CLI flag the app passes (`-p --output-format json --json-schema --system-prompt --model --effort --tools "" --strict-mcp-config --setting-sources "" --no-session-persistence`) exists in Claude Code 2.1.326.
- Storage keys use `path.join`, so `storage\export\…` works; `npm start` scripts use only `&&` and double quotes, which work in Command Prompt.
- Known Windows gotcha (unchanged): stop the app before `npm install`, or Prisma's engine DLL is locked (EPERM).

## Security spot checks (live)
Foreign `Host` header → 421; `X-Frame-Options: DENY`, CSP `frame-ancestors 'none'`, no `X-Powered-By`; `.env`, `*.db` and `storage/` not tracked by git; the rest is covered by the 85-check attack suite.
